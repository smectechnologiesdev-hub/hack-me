{% icon "book" "icon" %} Intelligence // Briefings

Clearance required — expand to decrypt.

Briefing 01 — Gaining access

Two ways in: brute-force the password with a wordlist (rockyou), or SQL-injection. The login is a classic vulnerable form — search "SQL injection login bypass".

Briefing 02 — The vault is sealed

The vault says to rotate your password first. Look in Profile → Data while you're there.

Briefing 03 — The leaked export

"Download my data" gives a JSON file. It over-shares: your username and vault_id are in plain text, plus two encryption keys (algorithm_key, vault_algorithm_key) and two encrypted values (encrypted_password, encrypted_vault_password).

Briefing 04 — Decrypt the evidence

Each encrypted value is AES-256. Website: open an "aes256" decrypt tool (e.g. encode-decode.com), paste an encrypted value as the text and its matching key (encrypted_vault_password → vault_algorithm_key) as the secret, hit Decrypt. Or open the bundled tools/vaultline_decrypt.html, or run tools/decrypt_vault.py. Decrypting encrypted_vault_password gives the vault password; the vault id is already in plain text.

Briefing 05 — Breach the vault

Rotate your password (unlocks the input), then type the plain-text vault id + the decrypted vault password. Download the file — the recovered intelligence is inside.
